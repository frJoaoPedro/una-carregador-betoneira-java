🏗️ SimuladorBetoneira -


📝 Descrição
Este projeto Java simula o processo de carregamento de uma betoneira

O software permite que um operador (você) insira o peso de "brita 1" adicionado em cada ciclo. O objetivo é atingir uma meta de peso predefinida de forma eficiente e controlada. O simulador não apenas rastreia o progresso, mas também avalia a precisão do operador no final, emitindo alertas se o limite de tolerância for ultrapassado, imitando um sistema real de controle de qualidade de concreto.
